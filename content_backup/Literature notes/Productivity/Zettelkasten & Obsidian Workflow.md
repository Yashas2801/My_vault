## Directory Structure
- ### Rough Notes
	- No Structure
	- Ideas that flash in my mind
	- Mostly use it in phone cause it is always accessible
- ### Literature Notes
	- A structured note which contains the knowledge I consume
	- Has a specific structure
	- Use Tags (Categorise)
	- Date
	- Create Outline
	- **Ref_image** 
		![[Screenshot from 2025-03-04 08-59-39 1.png|300]]
- ### Permanent Notes (Atomix)
	- Keep it Short (Atomic)
	- Don't copy paste **Write it in your own words**
	- Tags, Date
	- Connected Ideas 
	- Reference and sources
