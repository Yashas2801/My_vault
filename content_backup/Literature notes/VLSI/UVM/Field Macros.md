## do Hooks

**What are do hooks? :** They are callback, virtual methods which we can edit when the predefined method such as `copy` or `clone` or any other methods are called 

| Method Called by User | Virtual/callback Method |
| --------------------- | ----------------------- |
| **copy**              | [[do_copy]]             |
| **compare**           | do_compare              |
| **convert2string**    | -                       |
| **print**             | do_print                |
| **sprint**            | do_print                |
| **record**            | do_record               |
| **pack**              | do_pack                 |
| **unpack**            | do_unpack               |
